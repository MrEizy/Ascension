Builder's Zenith

Minecraft 1.21.1

Builder's Zenith adds a comprehensive set of building tools, decorative blocks, and construction utilities designed to help players create stunning structures — from ancient sect halls to modern fortresses.

⬇ CurseForge

What It Does

Builder's Zenith focuses on expanding the building experience in Minecraft with new blocks, tools, and quality-of-life features for builders. It integrates seamlessly with vanilla Minecraft and other Zenith mods.

New Blocks

Decorative Blocks

  • Carved Stone Variants — Intricate stone carvings inspired by Asian architecture
  • Spirit Wood Planks — Glowing wood planks in multiple colors
  • Jade Blocks — Smooth jade surfaces in green, white, and black variants
  • Tile Blocks — Roof tiles, floor tiles, and wall tiles in various patterns
  • Lattice Panels — Decorative window panels with geometric patterns

Functional Blocks

  • Pillar Blocks — Auto-connecting pillars that adjust top/middle/base textures
  • Arch Blocks — Curved blocks for creating doorways and bridges
  • Sloped Blocks — Diagonal blocks for creating roofs and ramps
  • Multi-Block Doors — Large doors spanning 2x3 or 3x4 blocks

Building Tools

  • Builder's Wand — Extend walls and floors by right-clicking the edge
  • Chisel — Modify block appearances and create custom carvings
  • Measuring Tape — Display distances and dimensions between points
  • Blueprint Scroll — Save and load building templates
  • Paint Brush — Change the color of applicable blocks without breaking them

Quality of Life

  • Symmetry Mode — Automatically mirror block placements along an axis
  • Ghost Preview — See a transparent preview before placing blocks
  • Batch Placement — Fill walls, floors, and ceilings in a single action
  • Undo System — Undo the last 20 block placements
💡 Tip: Combine Builder's Zenith with Ascension to create authentic cultivation sect buildings complete with spirit-infused architecture!
