EasyGUI

Minecraft 1.21.1 • NeoForge • Library Mod

EasyGUI is a retained-mode GUI framework for NeoForge. Instead of drawing every frame imperatively, you build a tree of RenderableElement objects, position them with rules, and respond to events. It handles transforms, Z-ordering, scissor culling, focus, and event propagation automatically.

⬇ Modrinth ⬇ CurseForge
💡 Tip: If you have ever written HTML/CSS, EasyGUI will feel familiar. Elements have IDs, classes, positioning contexts, and an event flow that captures, targets, then bubbles.

Overview

EasyGUI replaces the boilerplate of vanilla screen code with a declarative, object-oriented API. You create a UIFrame, attach a tree of RenderableElement nodes, and let the framework handle rendering, input, and layout. This makes complex UIs — draggable panels, animated menus, custom HUDs — straightforward to build and maintain.

Why EasyGUI?

  • Retained Mode — Build a scene graph once; the framework redraws it every frame.
  • Automatic Input Handling — Mouse, keyboard, scroll, and drag events propagate through the tree.
  • Flexible Positioning — Absolute, fixed, centered, and end-aligned rules out of the box.
  • Transforms — Rotate and scale elements around their center without manual matrix math.
  • Scissor Culling — Clip overflowing children with a single boolean flag.
  • Focus Management — Keyboard focus moves between elements automatically.

Quick Start

Creating a screen takes three steps:

  1. Create a UIFrame.
  2. Add elements to a root RenderableElement.
  3. Wrap the frame in an EasyScreen and open it.
// ============================================================ // 1. Create the frame — this is your top-level container // ============================================================ UIFrame frame = new UIFrame(); // ============================================================ // 2. Build a root element and add children to it // ============================================================ RenderableElement root = new RenderableElement(frame); root.setWidth(200); root.setHeight(100); EasyLabel label = new EasyLabel(frame); label.setText(Component.literal("Hello World")); label.setTextColor(0xFFFFFFFF); // Attach the label to the root root.addChild(label); // Attach the root to the frame frame.setRoot(root); // ============================================================ // 3. Open the screen // ============================================================ Minecraft.getInstance().setScreen( new EasyScreen( Component.literal("My Screen"), frame ) );
📘 Note: Component.literal("...") creates a vanilla Minecraft text component. EasyGUI uses these for all text rendering.

Core Concepts

UIFrame

The UIFrame is the top-level container. It owns the element tree, handles all input, manages IDs/classes for lookup, and drives the render loop.

PropertyDescription
rootThe top-level RenderableElement.
pauseGamePauses single-player when true.
useMinecraftScaleApplies Minecraft's GUI scale to the base transform.
tooltipGlobal EasyTooltip instance.
idMapElements indexed by string ID.
classMapElements indexed by class name.
focusedElementElement that receives keyboard events.
highestPriorityHoveredElementElement currently under the mouse cursor.

Key Methods

  • run(guiGraphics, mouseX, mouseY, partialTick) — Renders the tree and updates hover state.
  • onWindowResize(minecraft) — Recalculates transforms when the window changes.
  • mouseClicked / mouseReleased / mouseMoved / ... — Input entry points forwarded from the screen.
  • trySetFocus(element, focus) — Sets keyboard focus on an element.
  • setId(id, element) / addClass(classId, element) — Register elements for lookup.

RenderableElement

Every visual component extends RenderableElement. It is the backbone of the scene graph.

PropertyDescription
positioningPositioning instance defining layout.
transformTransform instance defining rotation/scale.
parentParent in the element tree.
uiFrameOwning UIFrame.
idString identifier for lookup.
classesList of class strings.
width / heightDimensions in pixels.
activeIf false, skips rendering and input entirely.
visibleIf false, skips rendering but still runs renderTick.
cullEnables scissor culling for children.
zIndexLocal Z-order offset (higher = on top).
childrenChild elements.
canBeFocusedWhether the element can receive keyboard focus.

Lifecycle

  • run(...) — Main loop. Applies pose, calls renderTick, then render, then children.
  • renderTick(...) — Called every frame even when invisible. Use for animations and logic.
  • render(...) — Called only when active and visible. Override to draw your content.
  • onRemove() — Cleanup hook when the element is removed from the tree.

Coordinate Helpers

  • getGlobalPoint() — Top-left corner in screen space.
  • getGlobalCornerPoint() — Bottom-right corner in screen space.
  • isPointBounded(x, y) — Hit test against element bounds.
  • globalToLocalPoint(x, y) — Screen mouse to local space (includes rotation/scale).
  • globalToLocalPositionPoint(x, y) — Screen mouse to local space (position only).

Layout & Positioning

Positioning System

Every element has a Positioning object that combines a context (coordinate space) and rules (alignment).

Contexts

ContextBehavior
ABSOLUTERelative to parent (or frame root). Identity matrix.
FIXEDFixed relative to the frame, ignoring parent transforms.

Rules

RuleX BehaviorY Behavior
STARTLeft / Top edge is at coordinate.Same.
CENTERCentered on parent/frame width.Centered on parent/frame height.
ENDRight / Bottom edge is at coordinate.Same.
⚠️ Note: END uses the parent's width/height to calculate the raw position. Positive values move inward from the edge.

Transform System

The Transform class handles rotation and scaling around the element's center.

PropertyDescription
scaleUniform scale factor.
useScaleWhether scaling is active.
xRotation / yRotation / zRotationEuler angles in degrees.

Transforms are applied after positioning in the pose stack. The pivot is the element's geometric center, so rotation and scale feel natural.

Event System

Events flow in three phases, just like the DOM:

  1. Capture — Travels from root down to the target element.
  2. At Target — Runs on the target itself.
  3. Bubble — Travels from the target back up to the root.

Any listener can call event.setCanceled(true) to stop propagation immediately.

Targeted Events

  • MOUSE_DOWN_EVENT, MOUSE_UP_EVENT, MOUSE_MOVE_EVENT
  • MOUSE_SCROLL_EVENT, MOUSE_DRAG_EVENT
  • KEY_DOWN_EVENT, KEY_UP_EVENT
  • CHILD_POSITION_TRANSFORM_CHANGED_EVENT, CHILD_TRANSFORM_CHANGED_EVENT

Global Events

  • FRAME_DIMENSIONS_CHANGE_EVENT
  • ELEMENT_POSITION_TRANSFORM_CHANGED_EVENT, ELEMENT_TRANSFORM_CHANGED_EVENT
  • GLOBAL_MOUSE_DOWN_EVENT, GLOBAL_MOUSE_UP_EVENT, GLOBAL_MOUSE_MOVE_EVENT
  • GLOBAL_MOUSE_SCROLL_EVENT, GLOBAL_MOUSE_DRAG_EVENT
  • GLOBAL_KEY_DOWN_EVENT, GLOBAL_KEY_UP_EVENT

Mouse & Key Events

EasyMouseEvent and EasyKeyEvent extend EasyEvent and carry detailed input data.

Built-in Elements

EasyButton

A clickable element with pressed and hovered states. Override onClick() to handle activation.

// ── Basic Button ── EasyButton btn = new EasyButton(frame, 10, 10); btn.setWidth(80); btn.setHeight(20); btn.setId("my_button"); // ── Custom Rendering via Subclass ── new EasyButton(frame, 10, 10) { @Override public void render(GuiGraphics g, int mx, int my, float pt) { int color = isPressed() ? 0xFF5555 : isHovered() ? 0x55FF55 : 0xFFFFFF; g.fill( 0, 0, getWidth(), getHeight(), color ); } @Override public void onClick() { System.out.println("Clicked!"); } };

EasyLabel

Text rendering with alignment, scaling, and auto-fit options.

PropertyDescription
textPositioningX / textPositioningYSTART, CENTER, or END.
textScaleUniform text scale.
fitWidth / fitHeightAuto-size container to text bounds.
maxWidth / maxHeightClamp auto-sized dimensions.
scaleToFitReduce scale so text fits inside fixed width.
colorText color (default 0xFF000000).
EasyLabel label = new EasyLabel(frame); // Text content label.setText(Component.literal("Centered Label")); label.setTextColor(0xFFFFFFFF); label.setTextScale(1.5f); // Alignment label.setTextPositioningX(EasyLabel.TextPositionRule.CENTER); label.setTextPositioningY(EasyLabel.TextPositionRule.CENTER); // Size label.setWidth(200); // fixed width label.setHeight(40);

EasyDraggableElement

An element that can be dragged with the left mouse button. Automatically brings itself to the front via zIndex.

💡 Tip: The drag offset is calculated in local space, so dragging works correctly even if the element is rotated or scaled.
EasyDraggableElement drag = new EasyDraggableElement(frame, 50, 50); // Size drag.setWidth(60); drag.setHeight(60); // Subclass render() to draw your own content inside

HealthBar

A survival-mode health bar that mirrors the player's health. It is positioned like the vanilla bar and increments leftHeight to avoid overlap with other HUD elements.

HealthBar health = new HealthBar(frame); // Position and size are pre-configured: // // width = 80 // height = 10 // X = centered // Y = END with offsets (-91, 39)

EasyTooltip

A tooltip element rendered via Minecraft's native tooltip system. It is inactive by default and clears its text when hidden.

EasyTooltip tooltip = new EasyTooltip(frame); frame.setTooltip(tooltip); // Activate and populate tooltip.setActive(true); tooltip.appendText(Component.literal("Hello")); tooltip.appendText(Component.literal("World")); tooltip.setScale(0.8f);

Screens & Overlays

EasyScreen

Wraps a UIFrame in a standard Minecraft Screen. All input is forwarded to the frame.

UIFrame frame = new UIFrame(); // ... build your UI ... EasyScreen screen = new EasyScreen( Component.literal("My GUI"), frame ); Minecraft.getInstance().setScreen(screen);

EasyContainerScreen

Extends AbstractContainerScreen and integrates EasyGUI with inventory slots. You can link a RenderableElement to a slot index, and the screen will use that element's transform/position for slot rendering, highlighting, tooltips, and floating items.

public class MyContainerScreen extends EasyContainerScreen<MyMenu> { public MyContainerScreen( MyMenu menu, Inventory inv, Component title) { super(menu, inv, title); UIFrame frame = getUIFrame(); RenderableElement root = new RenderableElement(frame); root.setWidth(176); root.setHeight(166); // Link slot 0 to a custom element RenderableElement slot0 = new RenderableElement(frame, 8, 18); slot0.setWidth(16); slot0.setHeight(16); slot0.setId("slot_index_0"); // required pattern root.addChild(slot0); frame.setRoot(root); } }
⚠️ Important: Slot elements must use the ID pattern slot_index_<n> so the container screen can map them to the correct inventory slot.

Overlays

Register HUD layers that persist outside of screens.

// In your mod init or client setup: UIFrame hudFrame = new UIFrame(); // ... build your HUD ... EasyOverlayHandler.registerOverlay( ResourceLocation.fromNamespaceAndPath( "mymod", "custom_hud" ), EasyOverlayPosition.ABOVE_ALL(), hudFrame ); // Override a vanilla layer (e.g. player health): EasyOverlayHandler.overrideVanillaOverlay( VanillaGuiLayers.PLAYER_HEALTH, myHealthFrame );

Textures

EasyGUI provides three texture data types that wrap Minecraft's blit methods.

TypeUse When
TextureDataRendering a full image file.
TextureDataSubsectionRendering a UV region from a larger atlas.
TextureSpriteDataRendering a sprite from the GUI atlas.
ITextureData icon = new TextureDataSubsection( ResourceLocation.parse("mymod:textures/gui/icons.png"), 256, 256, // texture size 0, 0, // u, v 16, 16 // region size ); // Inside an element's render(): icon.renderAt(guiGraphics, 0, 0);

Usage Examples

1. A Simple Menu Screen

public class MainMenuScreen extends EasyScreen { public MainMenuScreen() { super(Component.literal("Main Menu")); UIFrame frame = getUIFrame(); frame.setPauseGame(true); // ── Root fills the entire screen ── RenderableElement root = new RenderableElement(frame); root.setWidth(frame.getWidth()); root.setHeight(frame.getHeight()); frame.setRoot(root); // ── Title ── EasyLabel title = new EasyLabel(frame); title.setText(Component.literal("My Mod")); title.setTextPositioningX(EasyLabel.TextPositionRule.CENTER); title.getPositioning().setY(20); title.setTextScale(2.0f); root.addChild(title); // ── Play Button ── EasyButton play = new EasyButton(frame, 0, 60) { @Override public void render(GuiGraphics g, int mx, int my, float pt) { int c = isHovered() ? 0xFF66AA66 : 0xFF444444; g.fill( 0, 0, getWidth(), getHeight(), c ); g.drawString( Minecraft.getInstance().font, "Play", getWidth() / 2 - 10, 6, 0xFFFFFFFF ); } @Override public void onClick() { Minecraft.getInstance().setScreen(null); } }; play.setWidth(80); play.setHeight(20); play.getPositioning().setXPositioningRule(PositioningRules.CENTER); root.addChild(play); } }

2. Draggable Inventory Panel

// ── Create a draggable panel ── RenderableElement panel = new EasyDraggableElement(frame, 20, 20); panel.setWidth(140); panel.setHeight(100); panel.setShouldCull(true); // clip children // ── Background renderer ── new RenderableElement(frame) { @Override public void render(GuiGraphics g, int mx, int my, float pt) { g.fill( 0, 0, getWidth(), getHeight(), 0xCC000000 ); g.renderOutline( 0, 0, getWidth(), getHeight(), 0xFFFFFFFF ); } }; // ── Content inside the panel ── EasyLabel content = new EasyLabel(frame); content.setText(Component.literal("Drag me around!")); content.setTextColor(0xFFFFFFFF); content.getPositioning().setX(10); content.getPositioning().setY(10); panel.addChild(content); root.addChild(panel);

3. Responding to Global Events

// ── Recenter an element when the window resizes ── root.addEventListener( EasyEvents.FRAME_DIMENSIONS_CHANGE_EVENT, event -> { myElement.getPositioning().setX( frame.getWidth() / 2 ); } ); // ── Close a dropdown when clicking outside of it ── root.addEventListener( EasyEvents.GLOBAL_MOUSE_DOWN_EVENT, event -> { if (event.getTarget() != dropdown) { dropdown.setVisible(false); } } );

4. Custom Element with Transform

public class RotatedIcon extends RenderableElement { private final ITextureData texture; public RotatedIcon( UIFrame frame, int x, int y, ITextureData texture) { super(frame, x, y); this.texture = texture; setWidth(texture.getWidth()); setHeight(texture.getHeight()); // Rotate 45 degrees around the center getTransform().setZRotation(45); } @Override public void render(GuiGraphics g, int mx, int my, float pt) { texture.render(g); } }
💡 Remember: Transforms are applied automatically by run() before render() is called. You only need to draw at local (0,0).

5. Animated Progress Bar

public class ProgressBar extends RenderableElement { private float progress = 0f; // 0.0 to 1.0 public ProgressBar( UIFrame frame, int x, int y, int w, int h) { super(frame, x, y); setWidth(w); setHeight(h); } public void setProgress(float p) { this.progress = Math.clamp(p, 0f, 1f); } @Override public void render(GuiGraphics g, int mx, int my, float pt) { // Background track g.fill( 0, 0, getWidth(), getHeight(), 0xFF333333 ); // Filled portion int fillWidth = (int) (getWidth() * progress); g.fill( 0, 0, fillWidth, getHeight(), 0xFF3B82F6 ); // Border outline g.renderOutline( 0, 0, getWidth(), getHeight(), 0xFFFFFFFF ); } } // ── Usage ── ProgressBar bar = new ProgressBar(frame, 10, 10, 100, 12); bar.setProgress(0.75f); root.addChild(bar);

6. Tab Container

public class TabPanel extends RenderableElement { private final List<RenderableElement> tabs = new ArrayList<>(); private int activeTab = 0; public TabPanel( UIFrame frame, int x, int y, int w, int h) { super(frame, x, y); setWidth(w); setHeight(h); } public void addTab(String name, RenderableElement content) { int index = tabs.size(); // ── Tab Button ── EasyButton tabBtn = new EasyButton(getUIFrame(), index * 60, 0) { @Override public void onClick() { setActiveTab(index); } @Override public void render(GuiGraphics g, int mx, int my, float pt) { boolean active = (index == activeTab); int c = active ? 0xFF3B82F6 : isHovered() ? 0xFF555555 : 0xFF222222; g.fill( 0, 0, getWidth(), getHeight(), c ); g.drawCenteredString( Minecraft.getInstance().font, name, getWidth() / 2, 6, 0xFFFFFFFF ); } }; tabBtn.setWidth(58); tabBtn.setHeight(20); addChild(tabBtn); // ── Tab Content ── content.getPositioning().setY(22); content.setVisible(index == 0); tabs.add(content); addChild(content); } public void setActiveTab(int index) { activeTab = index; for (int i = 0; i < tabs.size(); i++) { tabs.get(i).setVisible(i == index); } } }

7. Hover Tooltip on Custom Element

public class ItemIcon extends RenderableElement { private final ItemStack stack; public ItemIcon( UIFrame frame, int x, int y, ItemStack stack) { super(frame, x, y); this.stack = stack; setWidth(16); setHeight(16); } @Override public void renderTick(int mx, int my, float pt) { // Show tooltip when hovered if (isHovered()) { EasyTooltip tip = getUIFrame().getTooltip(); tip.setActive(true); tip.clearText(); tip.appendText(stack.getHoverName()); } } @Override public void render(GuiGraphics g, int mx, int my, float pt) { g.renderItem(stack, 0, 0); } }
📘 Pro Tip: Use EasyScreen.debug(true) during development to visualize widget boundaries and event handling. It draws colored outlines around every element so you can spot layout issues instantly.
💡 Performance Tip: Set active = false on off-screen or hidden menus instead of just visible = false to skip both rendering and input processing entirely.
